## Drawn by the wick, routed with clarity.

A programmable network proxy and traffic routing engine.

Wickovia is built around a simple idea: make the path of network traffic deliberate and understandable. The project brings proxying and traffic routing together, with clarity at the heart of its design.

### What guides us

- **Intentional routing.** Make decisions about where traffic goes explicit.
- **Clarity in control.** Keep configuration, behavior, and feedback understandable.
- **Care in the details.** Give the engine and its interfaces the same attention.

### Project status

Wickovia is under active development. Public releases and documentation are not yet available. This organization will be the home for future public updates.
