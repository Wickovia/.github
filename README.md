# Wickovia organization profile

Public brand assets and the bilingual GitHub organization profile.

- English: [profile/README.md](profile/README.md)
- 简体中文: [profile/README.zh-CN.md](profile/README.zh-CN.md)

The English profile is the organization landing page. The language links open the Chinese version and return to the organization homepage. GitHub controls the surrounding layout; the banner follows the viewer’s preferred color scheme.

Brand assets follow the adopted Wickovia design system (workspace revision `afeee71`). The original logo is preserved in `profile/assets/logo.png`; the SVG banners embed the same PNG with a rounded display container. They contain no scripts, external fonts, or remote dependencies.
